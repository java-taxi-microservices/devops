# 🚀 Kafka Production Setup

Complete production-ready Kafka configuration with **SSL/TLS encryption** and **SASL/SCRAM authentication**.

## 📋 Quick Start

### 1️⃣ Generate SSL/TLS Certificates
```bash
./generate-certs.sh
```
This creates all necessary certificates and keystores in the `secrets/` directory.

### 2️⃣ Configure Environment Variables
```bash
# Copy example to .env
cp .env.example .env

# Edit .env and change passwords
nano .env
```

### 3️⃣ Start Kafka
```bash
docker-compose up -d
```

### 4️⃣ Access Kafka UI
Open your browser: **http://localhost:8280**

Login with:
- **Username:** `admin`
- **Password:** (from `KAFKA_ADMIN_PASSWORD` in .env)

## 🔐 Security Configuration

### SSL/TLS Certificates
- **Generated by:** `generate-certs.sh`
- **Location:** `./secrets/`
- **Validity:** 365 days
- **Key Size:** 2048 bits

### SASL/SCRAM Authentication
Two default users:
- **admin** - For broker & admin operations
- **client** - For application clients

### Connection Modes
| Port | Protocol | Use Case |
|------|----------|----------|
| 29092 | PLAINTEXT | Internal/Development |
| 29093 | CONTROLLER | Broker communication |
| 29094 | SASL_SSL | **Production (secure)** |

## 🛠️ Common Commands

### Manage Topics
```bash
# List topics
docker exec kafka kafka-topics.sh --list --bootstrap-server localhost:29092

# Create topic
docker exec kafka kafka-topics.sh \
  --create \
  --topic my-topic \
  --partitions 3 \
  --replication-factor 1 \
  --bootstrap-server localhost:29092

# Describe topic
docker exec kafka kafka-topics.sh \
  --describe \
  --topic my-topic \
  --bootstrap-server localhost:29092
```

### Manage SCRAM Users
```bash
# List users
docker exec kafka kafka-user-scram.sh \
  --bootstrap-server localhost:29092 \
  --list \
  --entity-type users

# Create user
docker exec kafka kafka-user-scram.sh \
  --bootstrap-server localhost:29092 \
  --create \
  --entity-type users \
  --entity-name newuser \
  --new-mechanism SCRAM-SHA-256 \
  --new-password password123

# Delete user
docker exec kafka kafka-user-scram.sh \
  --bootstrap-server localhost:29092 \
  --delete \
  --entity-type users \
  --entity-name newuser
```

### View Logs
```bash
docker logs -f kafka
docker logs -f kafka-ui
```

### Test Connection (from container)
```bash
docker exec -it kafka bash

# Test with PLAINTEXT (for debugging)
kafka-console-producer.sh \
  --broker-list kafka:29092 \
  --topic test-topic

# Test with SASL_SSL
kafka-console-producer.sh \
  --broker-list kafka:29094 \
  --topic test-topic \
  --producer-property security.protocol=SASL_SSL \
  --producer-property sasl.mechanism=SCRAM-SHA-256 \
  --producer-property sasl.jaas.config='org.apache.kafka.common.security.scram.ScramLoginModule required username="admin" password="'"$KAFKA_ADMIN_PASSWORD"'";'
```

## 🔄 Certificate Rotation

Certificates expire after 365 days. To rotate:

```bash
# 1. Backup old certificates
cp -r secrets secrets.backup.$(date +%Y%m%d)

# 2. Generate new certificates
./generate-certs.sh

# 3. Restart Kafka
docker-compose restart kafka

# 4. Distribute new CA certificate to clients
# Update CLIENT_EXAMPLES.md with new certificate content
```

## 🐛 Troubleshooting

### Kafka won't start
```bash
# Check logs
docker logs kafka

# Common issues:
# - Certificate permissions too open: chmod 600 secrets/*
# - Port already in use: lsof -i :29094
# - Environment variables not loaded: verify .env exists
```

### Connection refused (SASL_SSL)
```bash
# Verify credentials
echo "KAFKA_ADMIN_PASSWORD=$KAFKA_ADMIN_PASSWORD"
echo "KEYSTORE_PASSWORD=$KEYSTORE_PASSWORD"

# Check if broker is listening
docker exec kafka ss -tlnp | grep 29094

# Test from container
docker exec kafka kafka-console-consumer.sh \
  --bootstrap-server kafka:29094 \
  --topic __consumer_offsets \
  --from-beginning \
  --consumer-property security.protocol=SASL_SSL \
  --consumer-property sasl.mechanism=SCRAM-SHA-256 \
  --consumer-property sasl.jaas.config='org.apache.kafka.common.security.scram.ScramLoginModule required username="admin" password="'"$KAFKA_ADMIN_PASSWORD"'";'
```

### Kafka UI connection issues
- Verify `KAFKA_CLUSTERS_0_BOOTSTRAPSERVERS` = `kafka:29094`
- Check `KAFKA_ADMIN_PASSWORD` in .env
- Verify truststore path and password
- Restart kafka-ui: `docker-compose restart kafka-ui`
